ch_PP-OCRv3_rec_infer.onnx
==========================

PP-OCRv3 Chinese/English text-recognition model vendored for the canonical
RapidOcrService backend (rapidocr 3.4.5, ONNX Runtime). Vendored so installed
builds run the qualified recognizer offline, without user paths or runtime
model downloads.
